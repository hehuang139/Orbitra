# v1.1：兼容性证据与输入体验

本阶段承接环境诊断功能，推进浏览器验证与输入体验改进。本文同时记录实施范围和完成情况；没有承诺发布日期。一个 roadmap 对应一个实现 PR。2026-09-10 已实现输入配置与启动 / 存档适配层改进，缺少设备或人工证据的验收保持未完成，不能据此宣称整个 v1.1 已完成。

## 范围与优先级

| 优先级 | 任务 | 交付物与验收 |
| --- | --- | --- |
| P0 | 完成兼容性证据 | 记录 Chromium、Firefox、Safari、Android 和 iOS 的浏览器版本、系统、设备、部署响应头与日期；分别标识自动化、模拟视口和真实设备结果，未测试项保持待验证。 |
| P0 | 验证启动失败路径 | 非安全上下文、缺失隔离响应头、WebGL 与 Canvas 2D 均不可用、存储禁止或已满时显示具体原因；WebGL 2 不可用但 Canvas 2D 可用时进入软件渲染；配额检查失败不影响读取已有游戏库；错误不会修改已有存档。 |
| P0 | 记录低性能设备表现 | 在真实低性能设备运行原创 Star Orbit，分别记录正常运行与倒带的持续帧率、音频中断和内存观测方法；CPU 限速模拟只作为回归信号。 |
| P1 | 自定义手柄映射 | 支持非标准手柄的按钮与轴映射、死区设置、取消录入和恢复默认；设置按设备保存，断连或失焦后不残留按下状态。 |
| P1 | 触屏配置 | 提供布局预设、大小和透明度；设置持久化，支持多点触控、取消事件及横竖屏切换，按钮避开安全区域。 |
| P1 | 键盘与辅助技术 | 纯键盘完成导入、启动、暂停、存取档、退出；检查对话框焦点进入、限制与恢复，动态状态可被辅助技术读取。 |

## 实施顺序

- [ ] 先收集浏览器与设备基线，在兼容性记录中关联失败的最小复现步骤。
- [x] 完成启动失败回归；探测结果必须与实际可用能力一致，不能仅以 API 对象存在就宣称存档可靠。
- [x] 抽出独立输入配置与校验函数，旧版偏好设置迁移到默认配置，异常或未知配置不影响游戏启动。
- [x] 实现手柄映射，再实现触屏预设与持久化；保持核心输入接口和已有键盘映射兼容。
- [ ] 补齐完整键盘流程、窄屏布局和真实设备复测，更新 README 与 CHANGELOG。

## 本轮实现记录（2026-09-10）

- 手柄支持按设备标识和布局保存按钮 / 轴方向映射及死区，支持取消、单项清除和恢复默认；标准布局保留按钮、方向键与左摇杆，非标准布局从空映射开始。连接插槽变化不会丢失配置，存储禁止或 Gamepad API 访问异常有明确反馈。
- 触屏提供标准 / 紧凑布局、80%–130% 按键大小与 40%–100% 不透明度。旧设置补齐默认值，刷新保留配置；多指、指针取消 / 捕获丢失、失焦、暂停与横竖屏切换会正确释放按键。窄屏限制实际尺寸，控件预留安全区。
- 键盘快捷操作只在游戏画面聚焦时生效，界面保留正常 Tab 导航和按钮激活。启动、退出、对话框进入 / 限制 / 关闭与映射取消的焦点行为加入专用回归；键盘、手柄和触控共同持有同一按键时按来源释放。
- 核心适配层等待当前游戏完成首帧后才开放存取档；电池存档从核心原生快照提取当前 SRAM，避免立即暂停时读到虚拟文件系统中的旧数据。增加边界、大小与解压校验，保留启动超时和加载中释放处理。
- 未升级随仓库分发的 mGBA 核心，也未改变对外 `.sav` / 即时存档格式。快照解析仅用于核心原生输出，不能作为任意用户文件的解析接口。
- 已有 Edge / Windows 的真实应用自动化证据；手柄为模拟 Gamepad API，触控为合成指针与模拟视口。真实手柄、其他浏览器、移动设备、低性能硬件、音频试听和屏幕阅读器尚待验证，详见 [兼容性记录](../compatibility-matrix.md)。

## 验证与完成条件

基础检查为 `pnpm test`、`pnpm build`；输入和界面变更运行 `pnpm test:engine`、`pnpm test:ui`、`pnpm test:keyboard`、`pnpm test:gamepad` 和 `pnpm test:touch`。本轮保存和启动流程同时要求 `pnpm test:saves`、`pnpm test:startup`，ZIP 入口保留 `pnpm test:zip` 回归。单元测试包含 `src/emulator/battery-snapshot.test.ts` 的原生快照校验。设备断连、窗口失焦、映射取消、刷新恢复、共享按键和触控取消以可观察行为验证，不能用固定等待时间掩盖核心首帧或 SRAM 写回时序。

- [ ] 支持结论都能追溯到设备、版本、日期、步骤和结果。不能以 Playwright WebKit 代替 Safari 真机结论，也不能以窄屏视口代替手机性能测试。
- [ ] 至少一台真实低性能设备完成持续游玩和倒带检查；性能问题记录具体场景与复现资料，不设置未经基线验证的统一帧率门槛。
- [x] 手柄与触屏设置刷新后保留，旧配置正常迁移，模拟输入回归覆盖取消 / 恢复默认和按键释放。
- [ ] 320px 窄屏、常见手机尺寸与横屏没有横向溢出，安全区内的控件可达；PR 附桌面和手机效果图。
- [ ] 纯键盘关键流程与辅助技术人工检查完成；所有适用 CI 检查通过，存档兼容性影响写入 PR。

320×740、390×844、844×390 视口已有触屏布局自动化；这不等同于真实手机安全区、性能或辅助技术验收。缺少真机时保持相关任务未完成，并记录缺失设备与待验证步骤，不将其转成已支持结论。

## 阶段边界与后续

本阶段不包含批量备份恢复、离线安装、国际化、核心升级或云同步。下一阶段优先规划数据可携带性：带版本与校验和的备份格式、是否包含 ROM 的选择、恢复预览、冲突策略和事务回滚；本阶段未完成的真机与人工验收继续在本文追踪。PWA 在缓存版本与跨源隔离方案得到验证后单独规划，避免更新混用不兼容的核心资源。
