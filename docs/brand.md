# Orbitra 品牌指南

**Orbitra** 由 “orbit” 与 “era” 组合而来，表达不同平台、不同世代围绕同一个游戏库运行。中文口号为“所有经典，都在同一轨道。”，英文口号为 “Every era, one orbit.”。

## 标志

![Orbitra 横向标志](../public/orbitra-logo.svg)

- [`public/favicon.svg`](../public/favicon.svg)：正方形图形标，用于应用侧栏、favicon 与 PWA 图标。
- [`public/orbitra-logo.svg`](../public/orbitra-logo.svg)：图形标与英文名称组合，用于项目介绍和横向版面。
- 圆形主轨道表示统一的多核心运行时，交错的蓝色与珊瑚红轨道表示不同平台和世代，中心像素方块表示由用户掌控的本地游戏内容。
- 标志不使用具体主机、控制器或厂商商标轮廓，后续新增平台无需修改基本图形。
