# wasm-dolphin runtime

This directory contains browser runtime files from wasm-dolphin commit
`7e38409ace3dda709c178312ff63fd92a3653cc7` and a Dolphin WebAssembly core built from commit
`e22551eae1c84a7e4d0b6a5c519ef4ed4ef69df1`.

The bundled core file `cores/dolphin/dolphin-core-upstream.wasm` has SHA-256
`d7395b3a94080f5b7d08a0522f59096007419d117b7b0eb868246429adee6f5c`.
